🎮 <rpg-overworld> demo

Click the game to focus it, then move with Arrow Keys or WASD.

Press Space or Enter to interact with the tile in front of you.

Transfers between Town and Route happen via the gate (edge) and the doorway trigger.

Embed snippet (copy/paste)

<script type="module" src="./overworld/rpg-overworld.js"></script>
<rpg-overworld></rpg-overworld>

Because the component uses Shadow DOM, CSS collisions are extremely unlikely.
